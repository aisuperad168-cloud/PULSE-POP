👀 直播工程師的一天長什麼樣？

以晚班 17:00-02:00 為例，實際的一天：

17:00 – 17:30
巡檢 5-8 間

檢查每個直播間器材（電腦、路由器、燈光、麥克風），跑 ping 測試主要網段延遲，記錄異常。

17:30 – 19:00
開播前設定

協助主播開播前的推流設定、位元率調整（多數 6000 kbps / H.264 / CBR）、多平台同時推流測試、場景切換確認。

19:00 – 23:00
直播高峰期 on-call

排除斷流 / 卡頓 / 破音 / 閃退等突發。這是最緊張的 4 小時。能不能 10 分鐘內把主播救回線上，決定當晚的營收。

23:00 – 01:00
下播後保養

主播下播後保養器材（清潔、韌體更新、備份 OBS 設定 preset），寫技術日報（異常事件、器材狀態、待處理項）。

01:00 – 02:00
收拾鎖門

最後檢查、關機、鎖門、警報啟動。

📋 面試流程與時程

  1. 履歷篩選（Day 0-5）：收到後 5 個工作天內回覆。作品集 / GitHub / 直播經驗證明必附
  2. 初試（Day 6-12）：線上視訊 45 分鐘，含 技術問答（推流原理、位元率計算、常見斷流排除）
  3. 複試（Day 13-20）：實體到台中直播間 90 分鐘 + 現場實作測驗（給你一個故障情境，30 分鐘排除；不會就給你 3 次提示）
  4. Offer（Day 20-25）：全公司通過後 3 天內發正式 offer
💡 實作測驗說明：不是考你會不會背 OBS 選單，而是看你的排錯思路。例如「主播說直播卡卡的，你手上有 OBS + 路由器 admin 頁 + 電腦效能監控」，我們看你的分析順序與判斷力。就算你當場沒排除，思考邏輯清楚也算通過。

❓ 常見問題 FAQ

只會 OBS，不會 vMix / Wirecast 可以應徵嗎？
可以。OBS Studio 是必備門檻（推流原理、位元率、場景切換、外掛設定），vMix / Wirecast 是加分項。JDI 目前 8 成直播用 OBS，2 成用 vMix 做導播秀。到職後會有 2 週的 vMix 教育訓練，通過內部考核可申請 vMix Certified Operator 認證（公司補助費用），通過另有 3,000-10,000 元認證獎金。
40-60K 薪資怎麼算？技術認證獎金怎麼給？
依技術力核薪：2-3 年 40-45K；3-5 年含 vMix / 攝影棚背景 45-52K；5 年以上有電視台 / 演唱會 / 直播籌建經驗 52-60K。認證獎金每張 3,000-10,000 元（依含金量）。器材採購決策權（單筆 30 萬以下）。年終 1-3 個月。年收 55-85 萬。
5-8 個直播間網路怎麼配置？會用到什麼專業器材？
JDI 台中直播間：主線 500M 光纖 + 200M 備援 + 4G LTE failover。核心交換器 Cisco Catalyst，AP 用 Ubiquiti UniFi。每包廂 i7 電腦 × 1、環形燈 + 柔光箱、動圈 / 電容麥、Yamaha AG03 / GoXLR mini 混音器。導播工程用 vMix + Blackmagic ATEM Mini Pro。所有設備清單會在到職第一週交接。
工程師需要輪大夜嗎？可以完全遠端嗎？
目前是兩班制：早班 14:00-23:00、晚班 17:00-02:00，沒有大夜。單週最多輪 1 次晚班。這個職位不能全遠端——直播間的網路 / 燈光 / 音響故障必須人到現場排除。但白天沒事的時段可以做遠端工作（寫 SOP、監控儀表板、韌體更新），我們對「屁股一定要在椅子上」沒興趣。
工程師的職涯發展路徑？
JDI 內部升遷：資深工程師 → 技術主管（管 3-5 位工程師 + 器材採購 + SOP 制定）→ 技術總監（管全公司 3-5 個直播間 + 新直播間籌建）。外部發展路徑很廣：MCN 技術長、電視台工程師、演唱會 / 展會技術總監、自己開直播工程外包公司。直播工程師在台灣是稀缺人才，2-3 年後轉職通常能拉薪 40-60%，或自行接案時薪 800-1,500 元。
面試需要準備作品集嗎？
強烈建議帶。可以是：(1) 你曾負責的直播 / 攝影棚 / 演唱會案例（含技術規格、遇到的問題、如何排除）；(2) 你自己架的推流測試（OBS 設定截圖、位元率調校紀錄）；(3) GitHub 上的網管 / 自動化腳本。沒有作品集也可以面試，但複試實作測驗會更嚴格。
