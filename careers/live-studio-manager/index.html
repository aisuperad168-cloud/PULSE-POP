👀 直播間店長的一天長什麼樣？

以早班 14:00-23:00 為例，實際的一天：

14:00 – 14:30
開店 SOP

器材測試（燈光、麥克風、電腦、網路）、包廂清潔複檢、飲水零食補給、確認清潔外包完成度、簽收物料。

14:30 – 15:30
班表確認

檢核當日主播班表、確認 5-8 個包廂調度、LINE 通知遲到 / 請假主播、與經紀人同步異常。

15:30 – 18:00
主播進場潮

10-15 位主播陸續到場，處理臨時包廂調換、器材小狀況、化妝師交接、衣裝準備。這段是「機場地勤」時段。

18:00 – 21:00
直播高峰期

主播全數開播，跑動巡場、支援突發（斷網、音響故障、粉絲鬧場、主播情緒），與技術工程師配合排除問題。這是全天最緊張的 3 小時。

21:00 – 22:30
收播 & 盤點

主播陸續下播，收器材、清潔複檢、物料盤點、鎖門檢查。

22:30 – 23:00
日報回饋

打當日營運日報（包廂使用率、出席率、異常事件），交接晚班同仁（若有），下班。

💡 一句話定位：你不管內容（那是經紀人），不做剪輯（那是剪輯師），也不處理主播情緒的長期輔導（那是經紀人）—— 你是直播間這個「場域」的機長，管流動、管器材、管班表、管突發。

💰 薪資結構：40-55K + 夜班津貼 + 季度獎金

底薪只是起點。加上夜班津貼、季度營運獎金、年終，實際年收落在 55-80 萬區間。

經驗 底薪 年收預估
跨產業店長轉職（餐飲 / 零售 / KTV） 40,000 – 45,000 55-62 萬

額外收入

  • 夜班津貼：晚班 17:00-02:00 每班 300 元、大夜（目前無）500 元
  • 季度營運獎金：5,000-25,000 元 / 季（依包廂使用率、主播出席率、投訴率）
  • 年終：1-3 個月（依公司獲利 + 個人 KPI）
  • 加班費：例假日出勤依勞基法加倍
🔍 對比說明：台灣一般餐飲店長月薪 35-45K、KTV 幹部 38-50K（但作息傷身）、攝影棚場控 40-55K。JDI 的優勢是「娛樂產業薪資 + 相對正常的作息 + 不用陪酒」。

🌱 給跨產業店長：KTV / 夜店 / 攝影棚 / 高級餐廳的經驗完全可轉移。前 1 個月會有資深店長帶你熟悉 SOP 與器材，你不需要事先懂 TikTok 或直播技術，直播相關知識邊做邊學。真正的核心能力是現場管理與突發應變。

📋 面試流程與時程

  1. 履歷篩選（Day 0-5）：收到後 5 個工作天內回覆
  2. 初試（Day 6-12）：線上視訊 30 分鐘，由 HR + 現任資深店長面談
  3. 複試（Day 13-20）：實體到台中直播間 60-90 分鐘，含現場走一圈參觀 5-8 個包廂 + 認識團隊，含營運部主管加執行長
  4. Offer（Day 20-25）：全公司通過後 3 天內發正式 offer

複試會給 1-2 個情境題（例：晚班發生斷網 + 主播情緒崩潰 + 隔壁包廂衝突 3 件事同時發生，你怎麼優先排序）。沒有標準答案，看的是你的優先排序邏輯與冷靜度。

❓ 常見問題 FAQ

直播間店長一天實際做什麼？
以早班 14:00-23:00 為例：14:00 開店 SOP → 14:30-15:30 班表確認 → 15:30-18:00 主播進場潮 → 18:00-21:00 直播高峰期跑動巡場 → 21:00-22:30 收播 & 盤點 → 22:30-23:00 打當日營運日報。
沒做過直播間，只做過 KTV / 夜店 / 餐廳店長可以應徵嗎？
非常歡迎，這正是我們主要招募的族群。KTV / 夜店 / 攝影棚 / 高級餐廳的店長經驗完全可轉移：現場管理、多線突發處理、輪班文化、員工排班、客訴應對——這些技能 90% 可直接套用到直播間營運。你不需要事先懂 TikTok 或直播技術，前 1 個月會有資深店長帶你熟悉 SOP。
40-55K 薪資怎麼算的？夜班津貼怎麼給？
底薪依經驗核定：跨產業店長 40-45K；有直播 / 攝影棚 / 娛樂場館 3 年以上 45-50K；曾管 3 家店以上 50-55K。夜班津貼：晚班 17:00-02:00 每班 300 元。季度營運獎金 5-25K / 季。年終 1-3 個月。年收 55-80 萬。
輪班會很累嗎？有大夜嗎？
JDI 目前是兩班制：早班 14:00-23:00、晚班 17:00-02:00。目前沒有大夜（早上 7 點打烊）。單週最多輪 1 次晚班，其他 4 天都是早班。週休二日、國定假日輪休。相比 KTV / 夜店的大夜文化，這裡是「娛樂產業裡最健康的班別」。
店長要管幾個人？下面有多少主播？
你不直接管理主播的內容（那是經紀人），但需要管理現場流動：每天約 10-15 位排班主播進出、5-8 個包廂使用調度、跨部門協作 3-4 位技術 / 化妝師 / 清潔外包。直接下屬 0-2 位（副店長 / 值班經理，看營運規模）。你是「直播間的機長」——不做內容，但保證整台飛機安全起飛。
應徵店長的面試流程？
3 關流程：(1) 履歷篩選 5 個工作天內回覆；(2) 初試線上視訊 30 分鐘；(3) 複試實體到台中直播間 60-90 分鐘 + 現場走一圈參觀 5-8 個包廂，含營運部主管加執行長。複試會給 1-2 個情境題（例：斷網 + 主播情緒 + 隔壁包廂衝突 3 件事同時發生，怎麼排序）。
