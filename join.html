05 FAQ

你可能會 想問的

沒有直播經驗可以加入嗎？
當然可以。JDI 300+ 位主播裡，超過一半是「從 0 開始」的新手。免費培訓、器材支援、1v1 運營全程陪跑，你只需要「願意在鏡頭前說話」就好。
我已經在別的平台有粉絲了，加入 JDI 有幫助嗎？
非常有幫助。JDI 專精短影音導流 × 跨平台推流（TikTok / META / 線下廣告），我們會協助你把既有粉絲快速搬遷到 TikTok LIVE、對接業配代言，讓粉絲變成實際收入。
培訓要收費嗎？器材要自己買嗎？
培訓 完全免費，器材/設備依主播成長階段提供相對應支援方案，讓你 0 門檻起步。
簽約以後就一定要開播嗎？分潤怎麼算？
主播 0 抽佣 —— 你的禮物分潤依 TikTok 官方拆帳規則走，清楚透明。

公會層級的挑戰任務（例如衝月流水、達 KPI）是 JDI 自己要扛的事，跟你沒關係、也不會從你身上抽。你就專心開播、專心賺你的分潤跟業配。

開播時數依合約與個人狀況彈性協商，符合條件者還可申請 現金保底方案。所有數字簽約前都白紙黑字寫清楚。

JDI 支援哪些直播平台？可以同時播吗？
JDI 同時支援 TikTok LIVE、17LIVE、陸抖（抖音） 三大直播平台。

• TikTok LIVE：適合想衝全球流量、短影音曝光、業配代言天花板高的主播。

• 陸抖（抖音）：適合想入場大陸市場、拚嗆額度天花板高、衝單場流水的主播。

簽約前運營顧問會依你的個性、可開播時段、既有粉絲來源，建議一個主平台先起飛。後續完全 OK 跨平台同步發展（例如：白天 17LIVE 聊天陣營、晚上 TikTok 衝業配）。

可以。JDI 支援全職、兼職、學生檔期各種模式。運營會依你能開播的時段（例如晚上 21:00–24:00）幫你規劃最有效率的內容節奏與 PK 媒合。
