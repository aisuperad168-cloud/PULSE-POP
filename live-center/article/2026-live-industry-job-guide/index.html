直播產業 2026 求職指南：8 大職缺薪資 & 技能地圖

「我聽說直播產業薪水不錯，但根本不知道有哪些職缺、需要什麼技能、我原本的背景能不能轉職。」這篇一次講完。以 JDI 脈動傳媒公開薪資（30-60K）為基準，8 大職缺薪資完整揭露 + 每個職缺的必備技能 + 跨產業轉職對照表 + 熱門職缺深度解析。

一個直播公會裡的 8 種角色，8 種進入方式

台灣直播產業 2026 年估計已經是 200 億台幣規模的產業（TikTok LIVE + 17LIVE + 陸抖三大平台 + 品牌方投入的預算）。這個產業需要的不只是主播，還需要一整個團隊：經紀、業務、內容、技術、造型、行政。

但市場上的資訊很片段——你可能看過「主播月入 30 萬」的新聞，但幾乎沒人告訴你「直播公會員工月薪多少」「哪些技能能轉職進來」。這篇就是要補上這個空缺。

先講結論：這個產業對跨產業轉職者非常友善。8 大職缺裡有 6 個歡迎跨產業經驗（KTV 幹部、餐廳店長、客服、業務、行銷都可以找到對應職位）。

🎯 8 大職缺技能地圖

每個職缺的必備能力與加分能力，以及最適合的跨產業轉職背景。

1️⃣ 主播經紀人 · 33-45K

核心能力：溝通同理心、情緒管理、多線任務處理、Excel

加分能力：TikTok 演算法熟悉度、心理諮商 / 銷售背景、KOL 產業經驗

最適合的轉職者：客服中心 3 年以上、業務、諮商所畢業、教練職

不適合：喜歡明確 SOP 的人、不能忍受下午上班的人、討厭聽別人講心事的人

2️⃣ 主播招募 BD · 35-50K + 招募獎金

核心能力：陌生開發、私訊話術、社群識別能力、抗壓

加分能力：本身有直播 / 短影音經驗、HR / 獵頭背景、業務背景

最適合的轉職者：房仲、獵頭、電銷、業務、社群小編

不適合：內向不喜歡開發陌生人的、討厭 KPI 壓力的

特殊誘因：每簽約 1 位新主播 2,000-5,000 元獎金 + 季度招募王最高 30,000 元

3️⃣ 短影音企劃 / 剪輯師 · 35-48K

核心能力：Premiere / CapCut / DaVinci、TikTok 爆款結構、節奏敏感度

加分能力：After Effects、曾操盤破 100 萬觀看短影音、有作品集

最適合的轉職者：影像工作室、廣告後製、YouTuber 剪輯師、YouTube Shorts 創作者

不適合：不看短影音的、對「重複剪 30 支相似影片」感到痛苦的

特殊誘因：爆款獎金（單支破 100 萬觀看 3K / 破 500 萬 8K）

4️⃣ 直播間店長 / 場控 · 40-55K + 夜班津貼

核心能力：現場管理、多線突發處理、Excel 排班、抗壓

加分能力：KTV / 夜店 / 攝影棚場控背景、有主播接觸經驗、會基本器材檢修

最適合的轉職者：KTV / 夜店幹部、大型餐廳店長、旅館營運、攝影棚場控

不適合：不能接受輪班的、討厭現場工作只想坐辦公室的

特殊誘因：夜班津貼 300 元 / 班 + 季度營運獎金 5-25K

加分能力：有藝人 / 網紅 / 主播化妝經驗、Cosplay 造型能力、髮型設計證照

📈 職涯發展路徑（3-5 年後你在哪？）

路徑 A：內部升遷

  • 1-2 年：資深職（管 30-40 主播 / 5-8 位工程師 / 15 位員工，薪 45-55K）
  • 3-4 年：部門主管（管 3-5 位資深職 + 100+ 主播 / 團隊，薪 55-75K）
  • 5 年+：營運總監（管全公司線上或線下團隊，薪 70-100K+）

路徑 B：跳到更大平台

  • 大型 MCN（愛奇藝、字節旗下）當管理職：薪跳 20-40%
  • 品牌方 KOL 行銷（Uniqlo、資生堂等）：薪 50-75K，作息更正常
  • 電視台新媒體部門：薪 45-65K，福利好但節奏慢
  • 廣告代理商（Ogilvy、Dentsu 等）數位部門：薪 50-80K

路徑 C：自己出來做

  • 個人經紀人（簽 3-5 位頭部主播抽 15-20% 分潤）：年收有機會破百萬
  • 直播工程外包（幫其他公會 / 品牌做直播間籌建）：時薪 800-1,500 元
  • 短影音製作室（幫品牌 / 網紅剪短影音）：接案月收 10-30 萬
  • 直播培訓講師 / 顧問：時薪 2,000-5,000 元
💡 產業經驗的「稀缺加分」效應：因為直播產業還太新（2020 才崛起），有 2-3 年扎實直播公會經驗的人在市場上是稀缺人才。這是為什麼從直播公會跳槽通常能拉薪 30-50% —— 你會的東西不是「懂 TikTok 演算法」，而是「懂 TikTok LIVE 生態與變現運作」，這在傳統企業要花好幾年才能建立起來。

📋 面試準備清單

不管你想應徵哪個職位，這 3 個一定要準備：

1. CV 履歷（1-2 頁）

  • 明確標註跨產業轉職動機（一段話，例：「客服 3 年經驗培養的同理心，希望轉到主播經紀人這個更需要陪伴主播的角色」）
  • 過去可轉移的技能，用「動詞 + 結果」寫（例：「管理 30+ 客戶關係，客戶留存率 85%」而不是「負責客戶服務」）
  • 不要抄範本，公司看得出來

2. 作品集（技術類職位必備）

  • 剪輯師：1-2 支代表作 + 簡短說明剪輯思路
  • 化妝師：3-5 張作品照 + 造型企劃說明
  • 工程師：GitHub / 曾負責的直播 / 攝影棚案例（含技術規格）
  • 社群小編：自己經營的 IG 帳號 or 曾操盤的品牌帳號

3. 情境題準備

直播公會面試會問實務情境，例如：

  • 經紀人：「你的主播被酸民罵到直播中崩潰，你會怎麼處理？」
  • 店長：「晚班發生斷網 + 主播情緒崩潰 + 隔壁包廂衝突 3 件事同時發生，怎麼優先排序？」
  • 工程師：「主播說直播卡卡的，你手上有 OBS + 路由器 admin + 電腦效能監控，分析順序？」
  • BD：「一位潛力主播覺得公會抽成太高不想簽，你怎麼說服她？」

沒有標準答案，公司看的是思考邏輯與同理心。事先準備 2-3 個情境練習講出你的思路。

常見問題 FAQ

台灣直播產業 8 大職缺薪水多少？

以 JDI 2026 年公開薪資為例：行政人資 30-38K、社群小編 32-42K、主播經紀人 33-45K、招募 BD 35-50K、剪輯師 35-48K、化妝師 35-45K、直播間店長 40-55K、直播技術工程師 40-60K。加上季度獎金與年終 1-3 個月，實際年收約 40-85 萬區間。

沒有直播經驗可以進直播產業嗎？

非常歡迎，這是直播產業目前最大的紅利。8 大職缺裡有 6 個非常適合跨產業轉職者。剩下 2 個（剪輯師、直播技術工程師）需要技能基礎，但也不需要「事先懂 TikTok」，那可以到職後學。

直播產業什麼職缺薪水最高？

直播技術工程師月薪 40-60K + 認證獎金 3-10K / 張 + 器材採購決策權。這類職位在台灣稀缺，攝影棚 / 電視台 / 演唱會背景可直接跨進來。其次是「直播間店長」40-55K + 夜班津貼。

哪個直播產業職缺可以遠端工作？

混合遠端友善 4 個：主播經紀人、招募 BD、剪輯師（每週 2-3 天到辦公室）、社群小編（高比例遠端）。必須現場 4 個：直播間店長、直播技術工程師、化妝造型師、行政人資。

直播產業職缺需要什麼技能？

看職缺類別：內容經紀類需要溝通同理心 + Excel + 社群熟悉度；現場營運類需要現場管理 + 抗壓；技術類需要 OBS + 網路排錯；後勤需要 Excel + 細心。所有職缺都不需要「事先懂 TikTok 演算法」——那可以到職後學。

面試直播產業職缺要準備什麼？

3 個必備：(1) CV 履歷（明確標註跨產業動機）；(2) 若技術類職位帶作品集；(3) 情境題準備（主播情緒 / 客戶臨時取消 / 器材故障怎麼處理）。不需要事先研究 TikTok LIVE 技術細節。

直播產業職缺的職涯天花板在哪？

3 種發展路徑：(A) 內部升遷（3-5 年到總監級，薪跳 70-100K）；(B) 跳去大型 MCN 或品牌方 KOL 行銷（薪跳 30-50%）；(C) 自己創業（個人經紀、直播工程外包、培訓講師，年收有機會破百萬但風險高）。這個產業經驗在 2026 年是稀缺加分項。
