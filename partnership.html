01CORE · BROKERAGE

主軸：主播經紀 三大合作方案

JDI 是 TikTok LIVE 官方認證經紀公會，主業是主播經紀。 以下三種方案，涵蓋從機構到個人的所有合作需求：

CASE / A
🏢 經紀公司合作
🏢
經紀公司合作
整體納入 JDI 保護傘
你已經有 3-10 位主播、想升級為 TikTok 官方認證公會但資格門檻卡關？ 或是想省下自己申請、營運的時間？直接以工作室 / 小公會身份併入 JDI， 享受官方分潤通道、培訓體系、廣告資源與法遵支援。
  • 官方認證分潤通道，主播禮物拆帳按 TikTok 官方規則走
  • 培訓、後製、廣告投放、法遵支援共用 JDI 現有體系
  • 原團隊仍主導旗下主播管理，JDI 不干預內容方向
  • 公會層級 KPI 挑戰任務由 JDI 自扛，不轉嫁工作室
適合對象：3-10 位主播的個體工作室、未達 TikTok 官方公會門檻的小型團隊、 自營主播想找靠山的 podcast / 短影音團隊。
CASE / B
🔄 跨公會合作
🔄
跨公會聯播 / 資源互換
保留獨立性、放大彼此聲量
你已經是有規模的公會，不需要加盟，但想把彼此的主播、活動、粉絲池打通？ JDI 提供靈活的跨會合作框架：可以只做一次性活動聯播，也可以簽年度框架合約。
  • 雙方各自保留旗下主播經紀關係，只做「合作」不做「兼併」
  • 活動聯播、PK 對戰、達人客串、跨會主題週互相導流
  • 共同申請 TikTok / 17LIVE 大型平台活動 / 主題節目
  • 可延伸為市場拓展合作（例如共同進軍陸抖）
適合對象：已成規模的其他公會、經紀公司、MCN， 想擴大聲量但不想犧牲組織獨立性的合作夥伴。
CASE / C
🎤 個體戶簽約
🎤
個體戶主播 / 網紅經紀簽約
直播自主、業配交給我們
你已經是有粉絲基礎的主播 / 網紅，不想被公會綁住直播，但業配、代言、活動邀約想找專業經紀？ JDI 提供純經紀簽約：你的直播我不管、業配我幫你談。
  • 直播帳戶、內容方向、粉絲關係完全屬於你，JDI 不介入
  • 業配、代言、活動出席、廣告拍攝由 JDI 經紀團隊接洽與過稿
  • 合約條款、稅務、開票、匯款由 JDI 專業團隊處理
  • 符合條件可額外享有 JDI 培訓、拍攝棚、後製資源支援
適合對象：已在 IG / YouTube / TikTok 有一定粉絲的網紅、 Podcaster、模特、實況主，想找專業經紀但不想被公會綁住直播的個體戶。
