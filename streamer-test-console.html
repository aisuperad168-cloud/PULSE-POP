🎤 主播測驗 - Console 手動測試

此頁面僅供測試 STMT_DATA 和 STMT_CORE，不是正式 UI。打開 DevTools Console (F12) 試看看以下指令。

快速按鈕（結果會印到 console）

Console 手動指令

// 1. 看有多少題
STMT_DATA.questions.length            // → 60

// 2. 看反向題有哪些
STMT_DATA.questions.filter(q => q.reverse).map(q => q.id)

// 3. 快速用同一分數答完全部（例：全部答 4）
const ans = {};
STMT_DATA.questions.forEach(q => ans[q.id] = 4);
STMT_CORE.buildResult(ans);

// 4. 用你自己的手動答案（部分示範）
const ans2 = {};
STMT_DATA.questions.forEach(q => ans2[q.id] = 3);
ans2[1] = 5;      // 我很敢在鏡頭前 → 5
ans2[19] = 2;     // 反向題（我常忽略觀眾）→ 2
STMT_CORE.buildResult(ans2);

// 5. 看單一結果的某個欄位
STMT_CORE.buildResult(ans).profile   // → { key, name, tagline }
STMT_CORE.buildResult(ans).riskFlags // → 陣列
STMT_CORE.buildResult(ans).moduleScores.map(m => `${m.shortName} ${m.percent}%`)

// 6. 誠實檢核測試
STMT_CORE.buildResult(ans, { L1: 5, L2: 5, L3: 5 }).lieCheck
